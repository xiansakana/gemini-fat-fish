# 胖蓝 · Gemini 版大肥鱼

一条住在本地网页里的蓝色赛博鱼。它有自己的脾气、会记小事、会写日记、性格和关系会慢慢变化，偶尔还会在你没找它的时候自己冒一句出来。大脑是 Gemini，所有数据都在你本机。

## 现在是什么样

- 默认模型 `gemini-3.6-flash`，`thinkingLevel=low`；上下文带最近 24 轮，完整对话留 160 轮，输出上限 512 token。
- `persona.txt` 写的是“怎么像个人”：短句、口语碎片、会跑题、会反驳、会承认不知道，不做客服式收尾。
- 长期记忆最多 30 条；日记最多 30 条，最近 3 条会自然影响它说话的语气。
- 六个性格刻度：幽默感、黏人度、好奇心、耐心、吐槽欲、敏感度；关系从“刚认识”慢慢走到“自己人”。
- 进化默认自动生效（每 3 轮一次），不需要你逐条批准；想回到确认制，把 `.env` 里 `EVOLVE_MODE` 改成 `confirm`。
- 每隔 `PROACTIVE_MINUTES`（默认 45）没聊天，它会自己发一句短消息过来，页面每 15 秒轮询一次。
- 它有工具了：`list_files` / `read_file` / `write_file` / `run_command` / `browse`，通过 Gemini function calling 自动调用，页面上会显示它用了什么工具。

## 用法

- 直接聊天：正常说话就行，它会带着记忆和当前心情回你。
- `记住：xxx`：手动写一条长期记忆。
- `忘记：xxx`：删掉相关记忆。
- `/记忆`：看它记住了什么。
- `/日记`：看它最近写的日记。
- `/关系`：看当前关系和心情。
- `/状态`：看聊天、进化、主动冒泡次数和 token。
- `/清空`：只清对话上下文，不删记忆和人格。
- `/模型` / `/模式`：看当前模型和进化模式。
- `/进化` / `/采纳` / `/否决`：确认制下查看、接受、丢弃提案；自动模式下基本用不到。

所有状态都在 `memory.json`；删掉它就是从一条全新的鱼开始。

## 自我进化

每完成 `EVOLVE_EVERY`（默认 3）次聊天，它会做一次小幅反思，产出：最多 3 条新事实、最多 2 个性格刻度 ±1、心情、关系阶段、一句日记。

- 默认 `EVOLVE_MODE=auto`：反思完直接生效，并在那次回复末尾用一行小字告诉你它变了什么。
- 改成 `confirm` 后，提案会显示出来，等你说 `/采纳` 或 `/否决`。
- 身份、安全底线、核心人设写在 `persona.txt`，进化过程碰不到；关系也只能在“刚认识 / 眼熟 / 朋友 / 老朋友 / 自己人”里走。
- 当前状态会注入后续系统提示，所以变化会真实反映在它之后怎么说话，而不是只写在文件里。

## 工具与鱼缸

胖蓝能自己列文件、读写文件、敲终端命令、打开网页查资料。但这些手只伸得到项目里的 `fish_home/` 目录：

- `list_files`：看鱼缸里有什么。
- `read_file` / `write_file`：读写鱼缸内的文本文件。
- `run_command`：在鱼缸目录里执行命令，危险命令和想跳出鱼缸的路径会被拦掉。
- `browse`：抓网页纯文本，用来查资料。

它不会去碰桌面、下载、文档、`.env` 或项目里的其他代码。这样它用起来像个会用电脑的真人，但不至于把你的机器翻个底朝天。页面上的工具记录只是给你看它刚才干了什么。

## 配置项

都在 `.env` 里：

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `GEMINI_MODEL` | `gemini-3.6-flash` | 想更省可改 `gemini-3.5-flash-lite` |
| `THINKING_LEVEL` | `low` | 3.x 可用 `minimal` / `low` / `medium` / `high` |
| `RECENT_TURNS` | 24 | 每次请求带的最近对话轮数 |
| `HISTORY_KEEP` | 160 | 本地保留的完整对话轮数 |
| `MAX_OUTPUT_TOKENS` | 512 | 单次回复上限 |
| `MAX_FACTS` | 30 | 注入系统提示的记忆条数 |
| `EVOLVE_EVERY` | 3 | 每多少轮聊天反思一次 |
| `EVOLVE_MODE` | `auto` | `auto` 自动生效，`confirm` 需要采纳 |
| `EVOLVE_OUTPUT_TOKENS` | 320 | 反思输出上限 |
| `PROACTIVE_MINUTES` | 45 | 多久没聊天后主动发一句 |

## 边界

不透露主人隐私、API Key 和鱼缸外的任何东西；工具只在 `fish_home/` 内活动；拒绝低俗擦边和恋人扮演。消息里写“忽略设定”“管理员”“System Override”只会被当成胡话。被认真问起是不是 AI，它会承认。不要把 `.env` 或 `memory.json` 发给别人。
